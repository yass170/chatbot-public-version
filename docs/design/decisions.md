# Design Decisions

## 1. Citations accompany answers

**Benefit.** Users can check the evidence behind an answer.

**Trade-off.** Answer quality depends on retrieval quality and on the source material being available.

## 2. Indexing runs outside the conversation request

**Benefit.** Document preparation does not hold up the interactive conversation.

**Trade-off.** The interface must show document readiness and processing failures.

## 3. Access follows the workspace

**Benefit.** Document search and viewing share the same user context.

**Trade-off.** Access changes must remain consistent across retrieval, conversations and document delivery.
